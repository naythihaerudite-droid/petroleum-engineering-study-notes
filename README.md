# Petroleum Engineering Study Notes

A clean, beginner-friendly open study notes repository for core petroleum engineering topics.

## Purpose

This repository collects concise notes for learners who want a practical starting point in petroleum engineering. The notes are written in simple English and focus on key concepts before deeper textbook study.

This project is useful for:
- petroleum engineering students
- students preparing for exams or interviews
- learners from related engineering backgrounds
- beginners who want a quick conceptual overview

## Why this repo exists

Many engineering students need quick revision material that is less intimidating than full academic textbooks. This repository tries to bridge that gap by offering short notes, practical definitions, and simple study support.
