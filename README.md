# Petroleum Engineering Study Notes

A clean, beginner-friendly open study notes repository for core petroleum engineering topics.

## What this repo is for

This project is meant to collect concise, readable study notes for students who want a practical starting point in petroleum engineering. The notes are written in plain language, with short definitions, key formulas, and quick review points.

It is especially useful for:
- undergraduate petroleum engineering students
- students reviewing for exams
- learners from related engineering backgrounds
- anyone who wants a simple overview before reading full textbooks
